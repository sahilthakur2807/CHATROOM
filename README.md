# Blog + Chat Fullstack

Monorepo with `backend` (Express + Socket.IO) and `frontend` (Vite + React).

Getting started (development):

1. Backend

```bash
cd backend
npm install
cp .env.example .env
# edit .env as needed
npm run dev
```

2. Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

This repo is organized to implement features module-by-module. Work proceeds only after review of each module.
